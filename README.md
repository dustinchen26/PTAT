https://dustinchen26.github.io/PTAT

## 📌 功能特點

- **上傳即用**：支援點擊或拖曳上傳文字日誌檔。
- **完整解析**：自動擷取 CPU0 的所有數據點（包含 Index 0 校準點，可依需求調整）。
- **統計摘要**：顯示頻率、溫度、DTS、功耗、TMargin 的平均值、最大值、最小值與標準差。
- **異常偵測**：統計 TStat≠0x0、TMargin<0、DTS=0、頻率<2300MHz、功耗<200W 的次數，並給出綜合結論。
- **數據表格**：列出每一筆數據的時間戳、各項參數及異常原因（異常行以紅字標示）。
- **一鍵下載**：可將當前報告儲存為獨立的 HTML 檔案，方便分享或歸檔。
- **100% 客戶端**：所有處理均在瀏覽器中完成，不上傳任何資料至伺服器，確保機密性。

---

## 🚀 使用方法

1. **開啟網頁**：使用任何現代瀏覽器（Chrome、Edge、Firefox 等）開啟 `ptat_report.html` 檔案。
2. **上傳日誌檔**：
   - 點擊上傳區域，選取您的 `*_ptatmon.txt` 檔案；或
   - 直接將檔案拖曳至上傳區域。
3. **自動產生報告**：上傳後會立即解析並顯示完整報告。
4. **下載報告**：點擊頁面下方的 **「⬇️ 下載報告 (HTML)」** 按鈕，即可將目前報告儲存為 `report.html`。

---

## 📂 支援的檔案格式

- 必須是文字檔，副檔名為 `.txt`。
- 內容格式需與 `20260819_070809_ptatmon.txt` 範例一致（包含標題列 `Timestamp Index Device ...`）。
- 編碼建議使用 UTF-8（若為 ANSI 或其他編碼，請先轉換為 UTF-8）。

---

## ⚙️ 自訂與調整

- **顯示全部數據**：預設會顯示所有 CPU0 數據（包含 Index 0）。若您想跳過 Index 0（校準點），可編輯 HTML 檔案，在 `parsePtamonFile` 函數中找到 `// if (index === 0) continue;` 這一行，將註解移除即可啟用跳過邏輯。
- **調整異常條件**：您可在 `getAbnormalReasons` 函數中修改頻率下限（目前為 2300MHz）、功耗下限（200W）等閾值。

---

## 🛠️ 技術細節

- 純 JavaScript + HTML + CSS，無需任何第三方套件或伺服器。
- 檔案讀取使用 `FileReader` API，報告生成使用 DOM 操作。
- 相容於 IE11 以上及所有現代瀏覽器。

---

## ⚠️ 注意事項

- 若日誌檔案過大（超過數萬筆），瀏覽器可能因渲染大量表格而略微延遲，但一般測試檔案（數千筆）均可順暢執行。
- 請確保日誌檔中的每一行均為完整欄位（至少 29 個欄位），否則該行會被忽略。
- 若上傳後無反應或出現錯誤，請檢查檔案編碼是否為 UTF-8，或確認內容格式是否正確。

# PTAT report generator

https://dustinchen26.github.io/PTAT

## 說明
使用者可以直接上傳 `*_ptatmon.txt` 日誌檔，並在瀏覽器中產生測試報告（包含統計摘要、異常偵測、完整數據表格），並提供下載報告 HTML 的功能。

---

### 📄 功能說明
- **上傳檔案**：點擊或拖曳上傳 `*_ptatmon.txt`。
- **自動解析**：依相同邏輯（跳過 Index 0，只取 CPU0 資料）提取數據。
- **產生報告**：顯示統計摘要、異常偵測、結論及完整數據表格（含時間戳、異常標示）。
- **下載報告**：可將目前產生的報告儲存為獨立的 HTML 檔案。

---

### 🚀 使用方式
1. 將下方完整 HTML 程式碼儲存為 `ptat_report.html`（或其他檔名）。
2. 用瀏覽器開啟該檔案。
3. 上傳您的 `*_ptatmon.txt` 檔案。
4. 檢視報告，並可點擊「下載報告」按鈕保存。

---

### 📌 注意事項
- 所有處理均在用戶端瀏覽器進行，不會上傳至任何伺服器。
- 支援 UTF-8 編碼的日誌檔。
- 如果檔案格式不符，會顯示錯誤訊息。


### 🖥️ 畫面預覽
- 上傳區域支援點擊與拖曳。
- 解析完成後，報告會直接顯示在下方，包含所有統計圖表（純文字）與完整數據表格。
- 點擊「下載報告」可將目前報告儲存為獨立的 `report.html`，方便分享或存檔。

---

### 📝 備註
- 若檔案內含 BOM 或特殊編碼，請確保儲存為 UTF-8 格式。
- 此工具僅供前端使用，不需網路連線，資料不會外洩。

現在您可以直接將上述 HTML 程式碼儲存成 `.html` 檔案，用瀏覽器開啟即可開始使用。
